# Contributing

1. Open an issue describing use case, threat model and affected accounts/Regions.
2. Make changes on a feature branch.
3. Run Terraform fmt, init -backend=false and validate.
4. Run applicable static security and policy checks.
5. Add tests or explain why automated validation is not feasible.
6. Update diagrams, runbooks and delivery status when behavior changes.
7. Request peer review for IAM, SCP, network and logging changes.

Never submit credentials, Terraform state, production plans, customer identifiers or sensitive findings. Example policies are not production-approved by default.
